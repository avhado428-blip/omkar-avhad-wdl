Types of Laboratory Tests

Blood Tests

CBC, HbA1c and other blood-based investigations.

Urine Tests

Routine urine examination and related analysis.

Thyroid Profile

Laboratory investigations related to thyroid function.

Liver Function Test

Tests used to evaluate liver function.

Kidney Function Test

Tests used to evaluate kidney function.

Lipid Profile

Tests used to assess lipid-related parameters.

Diabetes Tests

Tests including HbA1c for blood sugar assessment.

Test Descriptions

CBC
Complete Blood Count used to evaluate overall health.
HbA1c
Measures average blood sugar levels over the past few months.
LFT
Evaluates liver function.
KFT
Evaluates kidney function.
ECG
Records the electrical activity of the heart.

Important: Please follow the preparation instructions before testing.
