Experiment 2 - CSS3 Implementation

Implemented tasks:
1. Inline CSS: header, h1 and slogan styling.
2. Internal CSS: navigation links, hover and text-decoration.
3. External CSS: style.css linked across the website.
4. Categories sidebar: border, padding, rounded corners, box-shadow, spacing and hover styles.
5. Card layout: laboratory test categories use inline-block/card styling with width, margin/padding, border, background and shadow.
6. Image gallery: consistent image sizing, borders, spacing, transition and transform: scale() hover zoom.
7. Price table: table.css with border-collapse, header styling, zebra striping using nth-child(even), centered text.
8. Registration form: form.css with input sizing, padding, focus/hover states, fieldset/legend, rounded corners and buttons.
9. Page layout: layout.css with header/sidebar/content/footer structure using flexbox and responsive media query.
10. CSS effects: animated glowing Offer box using @keyframes, text-shadow and box-shadow.

The original content and supplied images are retained; the HTML filenames were normalized so the existing navigation links work.
